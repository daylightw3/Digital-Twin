# Digital Twin - AI Avatar Landing Page

A modern, responsive landing page for Digital Twin AI Avatar services.

## Features

- Responsive design with mobile navigation
- Hero section with call-to-action
- Services showcase (4 AI avatar solutions)
- Integrated Calendly booking widget
- Testimonials section
- Case studies with downloadable content
- Blog section
- Modern UI with shadcn/ui components

## Getting Started

### Installation

```bash
cd frontend
npm install
```

### Development

```bash
npm start
```

The app will open at [http://localhost:3000](http://localhost:3000)

### Build

```bash
npm run build
```

## Technology Stack

- React
- shadcn/ui components
- Tailwind CSS
- React Calendly integration
- React Router DOM
